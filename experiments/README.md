# experiments

Experiment plans and records for hands-on testing on the Enygma Public
Testnet.

Rules:

- No experiment runs without approval first.
- Each experiment records its plan, the exact steps taken, transaction
  hashes, RPC responses, and what was actually observed.
- Testnet only. No mainnet activity, no spending beyond testnet gas.
- Results are observations first; any conclusion goes in `findings/`
  with its evidence label.
